# crown-powerwash-website
Website for a community-focused exterior cleaning organization.

## Overview

This project was created as a website for Crown Powerwash. The website provides information about services, contact information, and booking details in a clean and interactive format.

The project was designed to create an easy experience for users while also providing a professional online presence.

## Installation Instructions

1. Download or clone this repository.
2. Open the project folder.
3. Make sure all files are located in the same folder.
4. Open index.html in a web browser.

## Usage Instructions

1. Open the website in a browser.
2. Browse the services provided.
3. Use the contact and booking buttons for information.
4. Navigate through the page sections.

## Technologies Used

- HTML
- CSS
- JavaScript
